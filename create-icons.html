Glim Icon Generator

Generates all required PNG icon sizes for the Chrome extension. Click download and place the files in your icons/ folder.

Next steps

  1. Click Download All 4 Icons above.
  2. Move the downloaded files into the icons/ folder.
  3. Open Chrome → chrome://extensions
  4. Enable Developer mode (top-right toggle).
  5. Click Load unpacked → select the GLIM APP folder.
  6. Enter your Anthropic API key via the toolbar popup.
